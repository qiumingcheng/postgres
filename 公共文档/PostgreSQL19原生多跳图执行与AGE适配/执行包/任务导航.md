# 原子任务导航（V2：72 项）

完整定义见 [tasks.json](specs/tasks.json)，状态只用 [taskctl.py](scripts/taskctl.py) 维护。本表不存另一份完成状态。

5 项历史准备 G0-010/020/030/040/050 的定义和证据保留；新增 9 项均待实现。AGE 六项差异由 G0-035 继续处理；G0-060/070 仍依赖真实业务输入。V1 参考文件只作历史证据，活动任务使用 V2 契约。

## 必须读清的前置链

- 存储：GS-010/020/030 → GS-035 稳定 ref；GS-040 + GS-035 → GS-045 紧凑段 → GS-050/060/070；GS 正式门另依赖预注册业务输入。
- 批执行：G1-030 → G1-035 两层批 → G1-040 fixed runtime；不是 G2 才开始批量回表。
- 统计：G1-015 目录/发布 + G1-030 低层 provider → G1-025 单跳 → G1-046 短路径/物理 profile → G1-048 加载/校准 → G1-050 自然 CBO。
- 集成：G1-050 + GS-070 → G1-055 ref/provider → G1-060/070 → G1-075 统计/批/ref 联合回归 → G1-080。
- 产品化：GS-090 与 G1-080 同时完成后进入 G2；G2-040 只扩展自动维护/长路径，不补交首版统计。

ID 不表示唯一执行顺序；按依赖和 list-ready 领取，同一时刻一个 active task，不借并行代理绕过。
