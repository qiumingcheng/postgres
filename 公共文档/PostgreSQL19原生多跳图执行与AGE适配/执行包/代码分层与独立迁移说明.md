### AGE 正式开关与使用边界

新增内核 GUC **`enable_graph_age_adjacency`**，类型 boolean，默认 `off`，superuser 级；不再使用实验参数 `test_graph_core.visible_adj`。开关只控制公共执行器的 AGE 邻接交付，不是 AGE 扩展或 Cypher 的总开关。仅 `LOAD 'age'` 不启用此能力，也不构建这份邻接缓存。

```sql
SHOW enable_graph_age_adjacency;  -- off
LOAD 'test_graph_core';         -- 当前标准图执行的开发适配入口
LOAD 'age';                    -- 显式加载，不会自动打开开关
BEGIN ISOLATION LEVEL REPEATABLE READ READ ONLY;
SET LOCAL enable_graph_age_adjacency = on;
-- 原来的同一条 /*+ GraphRoute(btree) */ SELECT DISTINCT ... GRAPH_TABLE(...)。
-- EXPLAIN ANALYZE 实际访问标识应出现：
-- Graph Visible Adjacency: AGE transaction-private adjacency (experimental)
COMMIT;                         -- 释放缓存，SET LOCAL 恢复为 off
```

当前仍要求实际 superuser、非 security-definer 上下文、RR READ ONLY、无子事务/既有写入、永久 heap 且无 RLS/继承、已准入的固定 OUT WALK 端点集合。非此范围拒绝；显式打开而未加载兼容 AGE provider 也报错，不静默换路线。参数授权不能绕过 provider 的 superuser 安全门。只读事务内首次执行装载同一快照的顶点和边，后续可以复用；其他会话提交不刷新当前 RR 旧快照，下一个事务重新构建。该缓存不是 AGE VLE 的全局缓存，不跨事务。

关闭参数继续使用原来的图访问路径；不创建 AGE 图副本，不新增 DML 触发器/写入维护链。覆盖索引也不自动创建；用户未创建覆盖索引时，不会因为本功能新增一份索引的写维护。**这不等于已证明总体 DML 性能零开销**，生产读写压测、普通权限/事务支持、内存硬预算、成本选路仍未完成。
